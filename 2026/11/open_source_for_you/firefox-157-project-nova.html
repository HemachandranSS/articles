Firefox gets a new design

FOSS Bytes

Open Source For You  |  November 2026  |  Page 14, 15

Mozilla released Firefox 157, featuring a redesigned user interface as part of the Project Nova redesign. Changes cover navigation, tabs, icons, spacing, browser surfaces, the toolbar, menus and settings, plus updated themes and wallpapers shaped with Nightly-channel community feedback.

Developer-facing improvements include WebGPU support for the TRANSIENT_ATTACHMENT texture usage type for better memory efficiency; CSS support for the at-rule() function; and new administrative options for on-device speech recognition via an AIControls policy.
