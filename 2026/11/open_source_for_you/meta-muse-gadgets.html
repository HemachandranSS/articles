Meta launches Muse Gadgets for DIY hardware

FOSS Bytes

Open Source For You  |  November 2026  |  Page 14

Meta introduced Muse Gadgets, an open-source hardware initiative with SDKs (ESP32 Device SDK and Linux Device SDK) so developers can build custom devices connected to Meta’s Muse personal AI agent.

Firmware and SDKs are released under the Apache 2.0 license. Hardware targets include Raspberry Pi and ESP32-based boards with touchscreens and displays.

Key Terminologies

  1. Muse Gadgets (மியூஸ் கேஜெட்ஸ்)
  2. ESP32 Device SDK (இஎஸ்பி32 சாதன SDK)
  3. Apache 2.0 (அப்பாச்சி 2.0)
  4. Raspberry Pi (ராஸ்பெர்ரி பை)
