Fujitsu launches open source quantum application package

FOSS Bytes

Open Source For You  |  November 2026  |  Page 11

Fujitsu has released its Open Quantum Application Research Package (OpenQARP) as open source software to simplify quantum application development. The package provides more than 100 software components, including Fujitsu-developed quantum algorithms, that can be combined to build applications rather than implementing algorithms from scratch.

At its core, OpenQARP includes more than 70 composable building blocks covering functions such as state preparation, ansatz layers and the Quantum Fourier Transform. More than 20 ready-to-run algorithms are also provided, including Subspace-Search Variational Quantum Eigensolver for noisy intermediate-scale quantum systems and quantum phase estimation for fault-tolerant quantum computing.

OpenQARP is designed to run across a range of computing environments. It can be installed on a standard Python-capable PC and can integrate with Nvidia CUDA-Q as a backend through a source build for GPU-accelerated execution. It can also run on Fujitsu’s 40-qubit state-vector simulator, which uses 1024 PRIMEHPC FX700 systems equipped with A64FX processors.

The first open source release is v0.1.0 and is available under the Apache License 2.0, with the source code published on GitHub. By making reusable algorithms and development components openly available, the company aims to reduce the software effort involved in quantum application development and encourage broader experimentation.
