Fujitsu launches open source quantum application package

FOSS Bytes

Open Source For You  |  November 2026  |  Page 11

Fujitsu released the Open Quantum Application Research Package (OpenQARP), with over 100 software components including Fujitsu-developed quantum algorithms.

It features 70+ composable building blocks—state preparation, ansatz layers, Quantum Fourier Transform—and 20+ ready-to-run algorithms such as the Subspace-Search Variational Quantum Eigensolver. Targets include standard Python PCs, Nvidia CUDA-Q backends (GPU-accelerated), and Fujitsu’s 40-qubit state-vector simulator on PRIMEHPC FX700. Version 0.1.0 is under the Apache License 2.0 on GitHub.
