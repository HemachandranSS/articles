Anthropic debuts AI-powered security tool for open source code

FOSS Bytes

Open Source For You  |  November 2026  |  Page 10, 11

Anthropic has launched OSS Scanner, a free, opt-in service that uses its strongest language models, including Claude Mythos, to scan open source projects for security vulnerabilities automatically. This initiative aims to help maintainers patch weaknesses before attackers can exploit them.

AI-driven vulnerability detection has advanced rapidly. On the CyberGym benchmark, LLMs went from discovering under 20 percent of vulnerabilities early last year to over 85 percent currently, yielding significantly higher-quality bug reports. Through recent scans of critical software, their models identified over 29,000 potential vulnerabilities. However, human review capacity created a bottleneck, allowing them to triage only about 6000 of them.

Recognising that exploits can now be developed in minutes, maintainers increasingly request bulk submissions of unverified findings to accelerate patching.

Inspired by Google’s OSS-Fuzz, OSS Scanner complements Claude Security—Anthropic’s enterprise code-scanning product—by bringing free, high-powered defensive capabilities directly to the open source community. Maintainers can opt to receive fully model-generated reports instantly without human review. While this automated approach enables faster and more frequent audits, it carries a risk of occasional invalid reports.
