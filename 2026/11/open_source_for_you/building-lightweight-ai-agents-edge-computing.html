Building Lightweight AI Agents for Edge Computing

Lightweight AI models are making it possible to run intelligent applications directly on local devices. LangChain, Gemma and PaliGemma simplify AI agent development for edge computing while reducing reliance on cloud infrastructure.

Based on a talk by Supriya Sirbi · Transcribed by Ananthu Ashok

Open Source For You  |  November 2026  |  Pages 53–55

Artificial intelligence (AI) is increasingly moving beyond cloud-based environments and onto local devices. The change has created a growing need for lightweight language models that can intelligently respond without constant access to the internet. Running AI at the edge enables applications to operate in remote locations, improves privacy and reduces dependence on cloud infrastructure, making it suitable for many real-world scenarios.

One of the key enablers of this transition is Google’s Gemma family of open source models. Gemma models have been designed with smaller parameter sizes, and hence, they can be run on devices that have relatively modest hardware capabilities but can support various AI applications. In combination with other frameworks such as LangChain, developers can build intelligent agents that can perform tasks like image captioning, summarisation, and reasoning using only local systems.

Why lightweight models matter for edge AI

Running an AI model on edge devices has its own limitations and trade-offs must be made between inference performance and hardware limitations. While large language models use billions of parameters, sometimes even hundreds of billions, Gemma models have been designed in a way that they can function using merely 2 to 3 billion parameters, which is enough to function with 16GB RAM or even lower.

Edge AI becomes significant when there is no internet connection available. Regardless of whether they are working in remote areas such as forests or mountains where no internet is available, the models continue processing data locally and generate responses without internet connectivity. Since edge devices have limited computing resources, lightweight and fine-tuned models are better suited for these specialised use cases than large, general-purpose models.

Although lightweight models may introduce slightly higher inference times compared with powerful cloud-hosted systems, they offer the advantage of local execution, improved privacy, and independence from network connectivity.

What is LangChain?

LangChain is an open source framework designed for building AI agents, orchestrating workflows and experimenting with AI agents, agent architectures and agent orchestration. It enables developers to build intelligent systems without being tied to a specific language model.

One of its biggest advantages is its standardised model interface. Different language models, such as GPT, Gemma and others, expose different APIs. The abstraction offered by LangChain is that of providing a common interface to help developers easily switch between models.

Beyond providing a standardised interface, LangChain enables developers to build and orchestrate AI agents while experimenting with different agent architectures. It also supports data compression within agent workflows and provides observability, debugging and monitoring capabilities, providing greater flexibility for experimentation with different AI models.

With such characteristics, developers can try out increasingly advanced applications of AI without losing flexibility in relation to various models.

Why use LangChain?

One of LangChain’s biggest strengths is its ability to provide a standardised interface across multiple large language models. Whether developers are working with Gemini, ChatGPT, Claude or other models, LangChain abstracts their different APIs into a common framework, simplifying agent orchestration. This framework also allows for debugging, observability and monitoring capabilities.

Understanding the LangChain ecosystem

LangChain is just one component of an entire toolchain ecosystem where every tool performs a specific function within the context of AI application development.

  • LangChain: LangChain provides the entry point for building AI agents. It is suitable for developing straightforward applications such as image recognition, reasoning tasks and conversational agents without requiring complex orchestration.
  • LangGraph: The more sophisticated the application, the more powerful are the orchestration capabilities provided by LangGraph. This is because LangGraph enables multiple agents to coordinate tasks, manage workflows, and execute advanced agent orchestration.
  • Deep Agents: Deep Agents provide developers with lower-level control over AI systems. They are designed for scenarios requiring hardware optimisation.
  • LangSmith: Unlike the other components, LangSmith focuses on observability rather than agent execution. This includes monitoring, debugging, and visualisation of workflow, enabling developers to monitor and debug deployed agents.

Building an edge AI agent with Gemma

A practical example combines LangChain with Google’s Gemma models for building an AI application that can understand images and produce brief descriptions. It starts when an image is uploaded on the edge device by the user. An RGB conversion of the image takes place before it is analysed by PaliGemma, which is a vision-language model that has around 3 billion parameters. PaliGemma generates an image caption describing the uploaded image.

Once the image caption has been generated, a LangChain agent processes the output by invoking two separate tools. The first tool uses PaliGemma to generate an image caption, while the second uses the Gemma 2B model to generate a summary based on that caption. The agent then combines both outputs into a structured response containing the image caption and its corresponding summary.

Application workflow

The demonstration employs two lightweight AI models. PaliGemma (3B) is used to generate image captions, while Gemma 2B performs text summarisation based on those captions. Together, the models occupy approximately 7-8GB of storage, allowing the complete application to run locally on a standard laptop equipped with around 16GB RAM.

A Gradio web interface provides a simple front-end where users upload images and receive generated captions alongside AI-generated summaries. LangChain manages the communication of both models, enabling image captioning and text summarisation to be executed as a LangChain agent pipeline.

Rapid prototyping with Google Colab

Google Colab provides a convenient environment for experimenting with edge AI applications. Developers are allowed to choose hardware accelerators like NVIDIA T4 GPUs to accelerate the inference of their applications.

The workflow begins by installing the required libraries, including Transformers, LangChain, PyTorch, and other supporting packages. After installation, the runtime is rebooted and then the open source models are downloaded from the Hugging Face platform, which requires user authentication. After the models have been downloaded, LangChain components such as prompt templates, tools, agents, and language model chains are imported to begin building the application.

Loading lightweight Gemma models

The application uses PaliGemma 3B, a vision-language model designed for image captioning. Running locally, the model is configured to execute on the available hardware, whether CPU or GPU, while using an appropriate PyTorch data type for efficient inference. Although the compressed model occupies only a few gigabytes during deployment, downloading the complete model requires approximately 10GB of storage.

Once the model is loaded, uploaded images are converted into tensor objects before being passed to the captioning model. The model analyses the image and generates a descriptive caption, which serves as the input for the next stage of the pipeline.

Generating image summaries with Gemma 2B

The summarisation is performed using the Gemma 2B language model. The Hugging Face text generation pipeline is built and configured with a repetition penalty.

The model occupies approximately 4.9GB of space and is used along with the prompt templates and LangChain’s LLMChain to generate the summaries in a structured manner from the captions generated by PaliGemma. After the generation of summaries, the output is cleaned to deliver the result.

Integrating LangChain with Gemma

LangChain organises model capabilities into reusable tools that agents can invoke whenever required. In this implementation, the first tool performs image captioning by converting uploaded images into RGB format before passing them to the PaliGemma model for caption generation.

A second tool is responsible for text summarisation. Rather than performing an analysis on the images themselves, it uses the generated caption as its input and generates a short textual summary. Separating these functions into individual tools makes it possible for the LangChain agent to coordinate several AI models within one pipeline.

The LangChain agent acts as the central orchestrator of the application. It is initialised with the language model alongside two tools—the image captioning tool and the summarisation tool.

When an image is uploaded, the agent first invokes the captioning model to generate a textual description. It then forwards this caption to the summarisation model, cleans the generated output and returns a structured response containing both the detailed caption and its summary. The modular architecture allows combining various models in one workflow.

Creating the user interface with Gradio

Gradio offers the front end for the app. Users upload an image through the web interface, after which the LangChain pipeline processes the request and returns both the generated caption and summary.

Despite combining multiple AI models, the complete interface can be implemented using fewer than one hundred lines of code. The same implementation demonstrated in Google Colab can also be executed locally in development environments such as Visual Studio Code, where it operates successfully on systems equipped with approximately 16GB RAM.

Balancing performance and resource constraints

Running AI models locally comes with some trade-offs. Although edge computing guarantees that users’ privacy is protected and applications run without internet connectivity, inference for these takes longer when compared to the cloud.

Quantization is an optimization method. For instance, converting a 10GB model to 4-bit quantization can reduce its size to approximately 4GB. In addition, model distillation and lightweight architectures make it possible to implement AI on limited resources efficiently. Developers should implement guardrails like pre- and post-processing hooks to increase safety and effectiveness in edge AI.

Hardware optimisation and LangSmith

Unlike several higher-level orchestration frameworks, LangChain provides developers with greater control over hardware resources. It supports lower-level optimisation techniques that improve CPU, GPU and memory utilisation, making it particularly suitable for edge AI deployments.

For monitoring and debugging, LangSmith offers observability of the whole application. Workflow execution, reasoning processes, and agent interaction can be observed to facilitate problem solving and enhance transparency during development of the application using AI.

Choosing the right open source models

Different open source models are designed for different tasks. In this demonstration, Gemma 2B is selected because it performs well for text summarisation, while PaliGemma is better suited to image captioning.

Developers can experiment with different combinations of models to build applications that perform reverse workflows, such as generating images from summaries or validating whether uploaded images match accompanying documents. Understanding which model is best suited for a particular task remains an important part of developing efficient AI applications.
