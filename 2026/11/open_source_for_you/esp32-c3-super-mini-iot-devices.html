Creating Cutting-Edge IoT Devices with the ESP32 C3 Super Mini Board

The ESP32 C3 Super Mini board is a smaller but powerful alternative to the Raspberry Pi Pico boards. The MicroPython code in this hands-on guide (and its sensor interfacing) also works on the Pi Pico. Everything was tested on an Ubuntu LTS laptop with Docker installed.

By Ankur Kumar

Open Source For You  |  November 2026  |  Pages 73–79

The ESP32-C3 Super Mini is thumb-sized—less than half a Pi Pico—yet packs Wi-Fi, Bluetooth LE and enough I/O for serious sensor work. Pair it with MicroPython (Thonny, pyboard, mpremote) and you can prototype IoT gadgets quickly on Ubuntu with Docker for flashing and serial tools.

Flashing MicroPython

Plug the board via USB-C. Beginners can use Thonny: Interpreter → MicroPython (ESP32), port such as /dev/ttyACM0, then “Install or update MicroPython” (family ESP32-C3, variant Wemos C3 mini). For automation, use esptool—optionally in Docker so you need no host write access beyond the device node.

# Dockerfile_Esptool (python:3.14-alpine + esptool)
docker build . -f Dockerfile_Esptool -t esptool

# Download latest LOLIN_C3_MINI / ESP32 GENERIC C3 firmware from micropython.org
# Then erase and write (adjust port if needed):
docker run --rm -v /tmp/ESP32_GENERIC_C3_Latest.bin:/tmp/ESP32_GENERIC_C3_Latest.bin \
  --device=/dev/ttyACM0:/dev/ttyACM0 esptool erase-flash
docker run --rm -v /tmp/ESP32_GENERIC_C3_Latest.bin:/tmp/ESP32_GENERIC_C3_Latest.bin \
  --device=/dev/ttyACM0:/dev/ttyACM0 esptool write-flash 0 /tmp/ESP32_GENERIC_C3_Latest.bin

Onboard LED and internal temperature

Quick LED toggle via pyboard-in-Docker, then a fuller script (bleditemps.py) that flashes GPIO 8 and estimates die temperature from the internal ADC (Vbe ≈ 0.706 V at 27 °C, slope ≈ −1.721 mV/°C):

docker run --device=/dev/ttyACM0:/dev/ttyACM0 pyboard -c \
  'from machine import Pin;from time import sleep;p=Pin(8, Pin.OUT, value=1);p.toggle();sleep(3);p.toggle()'

docker run --rm -v ${PWD}/bleditemps.py:/etc/rpipico/bleditemps.py:ro \
  --device=/dev/ttyACM0:/dev/ttyACM0 pyboard bleditemps.py

External LEDs: electronic dice (chaseleds.py)

Wire five 10 mm LEDs (red, yellow, green, blue, white) anodes to GPIO 0–4 and cathodes to GND on a mini breadboard (Figure 4). The script chases LEDs forward/back, randomises them, then settles like a dice roll (1–5 single colours; 6 = all on). Helpers such as rledon() / yledon() … drive one LED at a time; randice() uses randint(1, 6). Full listing is in the page-76–77 scans.

PIR motion switch (pirmtnsnsr.py)

Mini PIR: VIN→3V3, GND→GND, signal→GPIO 4 (pull-down on ESP32-C3). RGB feedback on GPIO 0/1/3. Instead of busy-polling, an IRQ on rising edge runs mtnhdlr: red for dly seconds, brief blue, then green when idle.

pirs.irq(trigger=Pin.IRQ_RISING, handler=mtnhdlr)
# idle loop: green when no motion

IR obstacle sensor (obstklesnsr.py)

Module with IR TX/RX and comparator; green LED on detection. Code uses Signal for active-low logic on the sensor pin (GPIO 5) and RGB LEDs: red when obstacle present, green otherwise (Figure 6).

Air quality: DHT11, MQ-2 / MQ-135, TM1637

MQ-2 covers LPG/smoke/flammables; MQ-135 ammonia/CO₂-class contaminants. Heaters need 5 V and warm-up time. Pair with DHT11 for temp/humidity and a TM1637 4-digit display (library: mcauser/micropython-tm1637). The demo (tempnumgss.py, Figure 7) reads DHT + MQ2 AO, shows temp/humidity on the display, estimates chip temp, and maps thresholds to RGB: green ≤30 °C, blue 30–35 °C, red >35 °C.

Closing

The Super Mini is compact, affordable and MicroPython-friendly—an ideal companion to the Raspberry Pi ecosystem for edge IoT. Start with Thonny or Dockerised esptool, blink the onboard LED, then grow into chase LEDs, PIR, IR and air-quality stacks. Full source appears in the magazine scans (pages 73–79).

References: Esptool docs; MicroPython ESP32 quickref; micropython-tm1637 on GitHub.
