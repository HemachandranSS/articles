VolAnti uses sound analysis to identify drones

FOSS Bytes

Open Source For You  |  November 2026  |  Page 16

VolAnti is an open-source drone detection project by Agam Rossen. Unlike traditional detectors that monitor radio transmissions, it uses sound analysis—so it can detect fiber-optic FPV drones that evade conventional RF detection.

Hardware centres on an ESP32-S3 microcontroller and four ICS-43434 digital MEMS microphones in a cross pattern, plus LoRa for sharing alerts, an e-paper display, buzzer and vibration alerts, powered by a 2,500 mAh Li-Po pack (about 18–22 hours). Public resources include firmware, PCB files, BOM, enclosure designs, test audio and a browser-based simulator.
