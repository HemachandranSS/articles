OpenAI now allows enterprises to process AI requests within India

Balasubramanyam C.P.

CHENNAI  |  November 13, 2026

OpenAI has enabled local processing and inference for its API in India, so eligible businesses and developers can have AI requests and model computations handled entirely within the country.

The move expands a data-residency offering from May 2025 that let customers store data in India; the update covers processing and response generation. It targets regulated sectors such as financial services that need data localisation.

Local processing is initially available for the GPT-6 Luna model. Nitin Bawankule, Head of Enterprise - India, said some Indian businesses had held back AI deployment because information had to be processed abroad.

Key Terminologies

  1. Local inference / processing (உள்ளூர் ஏஐ செயலாக்கம்)
  2. Data residency (தரவு வசிப்பிடம்)
  3. GPT-6 Luna (ஜிபிடி-6 லூனா)
  4. Enterprise API (நிறுவன ஏபிஐ)
